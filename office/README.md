# نظام ميثاق للمحاماة — بيئة الفحص والتعديل

## التشغيل
- انقر مرتين على `start.bat` → يفتح النظام على http://localhost:8080
- للإيقاف: أغلق نافذة الخادم السوداء.
- بعد أي تعديل: احفظ الملف ثم حدّث الصفحة في المتصفح (F5).

## الملفات
| الملف | ماذا تعدّل فيه |
|---|---|
| `index.html` | هيكل الصفحة (الشريط الجانبي والبحث) |
| `style.css` | الألوان والخطوط والتخطيط — الألوان في أعلى الملف ضمن `:root` |
| `app.js` | البيانات والشاشات والمنطق |
| `server.js` | خادم محلي بسيط (لا يحتاج تعديلاً) |

## أماكن مهمة داخل app.js
- `OFFICE` — اسم المكتب والمحامي والمدينة.
- `courts` / `clients` / `opponents` / `cases` / `hearings` / `deadlines` / `docs` — البيانات التجريبية.
- `TPL` — نصوص النماذج القانونية. كل سطر في `body` هو سطر في المستند، والحقول بين `{ }` تُملأ تلقائياً من القضية.
- `MZ_INCOMING` — محاكاة تحديثات ميزان (تُستبدل لاحقاً بالربط الحقيقي).
- `TODAY` — التاريخ المعتمد في البيانات التجريبية.

## ملاحظات
- البيانات حالياً في الذاكرة وتعود لحالتها الأصلية عند تحديث الصفحة.
- الخطوة التالية المقترحة: قاعدة بيانات (SQLite) وتسجيل دخول للمستخدمين.
