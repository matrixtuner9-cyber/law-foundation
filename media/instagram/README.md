# محتوى انستغرام «المِسْبار» — ملف التسليم

هذا المجلد يحتوي كل ما لزم لإنتاج فيديوهات وصور انستغرام لـ«المِسْبار» و«ميثاق». الفيديوهات النهائية (MP4) لم تُحفظ هنا لحجمها، ويمكن إعادة توليدها من هذه الملفات.

## إعادة البناء (Linux + Node + Playwright + ffmpeg + Python3/numpy)

انسخ المجلد إلى `~/ig` (المسارات في `video.js` و`reel.html` مكتوبة على `/home/claude/ig`)، ثم:

```
# صورة إطارات للمعاينة:     node video.js <reel> 2,10,20
# فيديو بصوت:               AUD=vo/<file> node video.js <reel>
# موسيقى خلفية (ثوانٍ):      python3 music/make.py 60 music/bed.wav
# مزج صوت + موسيقى:          music/mix.sh vo/x.mp3 music/bed.wav vo/x-mix.wav
# المنشورات المصوّرة:        node render.js
```

`vo/dlgA2.wav` = `vo/dlgA.mp3` بعد حذف «يا زلمة» (0:34.76–0:35.50). يُعاد إنشاؤه بـ ffmpeg atrim/concat.
